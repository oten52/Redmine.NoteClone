# Changelog

## 0.1.0

* First release.
* Copy notes from an issue onto other issues, including the images attached to those notes.
* Side panel to edit the note text, choose images, and type any issue number the user is allowed to update.
* Related issues start selected. Parent and subtasks are listed and are not selected.
* Direct copy sends the notes, unchanged, to the related issues the user can update, without opening the panel.
* Source line with the original author and time. Watcher notification is off unless requested in the panel.
* Translations: English and Turkish.
